Entry for make.fun's “Build mend, one patch tool for every AI edit format” bounty. Write a command-line tool that applies AI-written edits in four formats (unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls) to a tree of files, to a specification that ships in the kit; 100 checks of its exit code, output and files are drawn after the deadline from a pool no kit carries. Places go by score, best first, so the highest score wins 1st place; a strict applier is entered as a house entry in the last hours, and a reward needs a score above it, so beating it only qualifies an entry for a place: it holds the place it finishes in and never takes that place's reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
